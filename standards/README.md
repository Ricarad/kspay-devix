# 工程规范

本目录保存跨仓库、跨需求长期有效的最小公约：

- [`coding.md`](./coding.md)：代码生成与修改规则。
- [`comments.md`](./comments.md)：注释风格与禁用模式。
- [`testing.md`](./testing.md)：测试设计和验证证据规则。
- [`release.md`](./release.md)：发布配置、环境差异、上线 SOP、监控与回滚规则。

这些文件是“缺省规范”，不是凌驾于业务仓库之上的总规范。编码前必须先阅读目标业务仓库根目录以及目标模块沿途适用的 `AGENTS.md`：仓库已经规定的内容按仓库执行，本目录只补充未覆盖项。

若某条规则只适用于一个仓库，应放进该仓库的 `AGENTS.md` 或未来的 repo profile，而不是继续膨胀全局规范。仓库规则与 Devix 缺省规则冲突时遵守仓库规则；与需求目标或安全 gate 冲突时则显式记录并请求确认。
